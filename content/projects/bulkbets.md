#### BulkBets

BulkBets is a full-stack bodybuilding betting demo with a Next.js web app, an Expo / React Native mobile app and a Go API backed by PostgreSQL. Visitors can try it without registering, using £1,000 in virtual funds to explore historical markets, build singles and accumulators, and simulate results.

The demo also includes a simulated wallet and a private event studio for managing shows, athletes, odds and settlement. No real money is used.
